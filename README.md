# Motown Nate's website

## Switching between open and closed for the season

1. Open `status.json` in this repo and tap the pencil (edit) icon.
2. Change `"open": true` to `"open": false` when the season ends, or back to `true` when it starts.
3. Optional: put a short message in `"note"`, for example `"Back Monday, May 4"`. Leave it as `""` for the default message.
4. Tap Commit changes. The banner on every page updates within a minute or two.

Nothing else on the site needs to change.
